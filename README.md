# Arnav's Portfolio

My personal portfolio showcasing cloud and DevOps projects, open-source contributions, and certifications.

[Visit the website](https://arnavsx3.github.io/portfolio/)

## What's inside

- Featured projects and more builds from my GitHub repositories.
- Merged open-source contributions, with searchable pages for each project.
- A little about me, my skills, and certifications.
- Links to get in touch.

## Built with

React, TypeScript, and Vite. Hosted on GitHub Pages.

## Run locally

Requires Node.js 24 and npm.

```sh
npm ci
npm run dev
```

Open [localhost:5173/portfolio/](http://localhost:5173/portfolio/).

To check the production build:

```sh
npm run build
npm run preview
```

## Automatic updates

Projects and open-source contributions refresh from GitHub every six hours. Repository descriptions, featured pins, merged PRs, and contribution counts stay up to date automatically.

To refresh manually, open **Actions → Verify and deploy portfolio → Run workflow** and select **main**.

## Publishing changes

Make changes on a feature branch, preview them locally, and open a pull request. Updates merged into `main` are checked and published automatically.
